# New Portfolio

Portfolio personal estático, responsive y accesible. No requiere dependencias ni proceso de build.

## Desarrollo local

Sirve la carpeta `dist/` con cualquier servidor HTTP estático.

```powershell
npx serve dist
```

## Personalización

- Contenido: `dist/index.html`
- Diseño: `dist/styles.css`
- Interacciones: `dist/script.js`
- System Design: `design/system-design.md`

El contenido evita afirmar experiencia, clientes o métricas no confirmadas. Sustituye los textos marcados como áreas de interés cuando dispongas de información profesional definitiva.
